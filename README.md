# LRU-Cache-System
A Java implementation of a Least Recently Used (LRU) Cache using a custom Doubly Linked List and Hash Table.

## Features
- Fast O(1) time complexity for lookup and insertion
- Custom Doubly Linked List for maintaining access order
- Evicts the least recently used item when capacity is reached

## Built With
- Java
- Data Structures (Doubly Linked List, Hash Table)
